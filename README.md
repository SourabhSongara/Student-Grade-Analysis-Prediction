📊 Student Grade Analysis & Prediction

📌 Overview

This project focuses on analyzing student data and predicting final grades (G3) using machine learning techniques.

🚀 Objectives

▪️ Analyze factors affecting student performance

▪️ Build predictive models for final grades

▪️ Compare multiple ML algorithms

🛠️ Tech Stack

▪️ Python

▪️ Pandas, NumPy

▪️ Matplotlib, Seaborn

▪️ Scikit-learn

📂 Dataset

▪️ Student dataset (student-mat.csv)

▪️ Includes:

    ▪️ Academic performance

    ▪️ Demographic details

    ▪️ Social behavior

🔍 Exploratory Data Analysis

▪️ Gender and age distribution

▪️ Urban vs rural comparison

▪️ Study habits vs grades

▪️ Social activities impact

🤖 Models Used

▪️ Linear Regression

▪️ ElasticNet

▪️ Random Forest

▪️ Extra Trees

▪️ Support Vector Machine (SVM)

▪️ Gradient Boosting

📈 Evaluation Metrics

▪️ Mean Absolute Error (MAE)

▪️ Root Mean Squared Error (RMSE)

📊 Key Insights

▪️ Students with more past failures tend to score lower

▪️ Excessive social activity slightly reduces performance

▪️ Ensemble models provide better accuracy
